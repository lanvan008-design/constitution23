# Конституция · 23

Тренажёр конституционных характеристик для задания 23 ЕГЭ по обществознанию.

Два режима: тренировка и до первой ошибки. Семь типов заданий: выбор подтверждения, несколько подтверждений, классификация, сборка ответа, поиск ошибки, поиск лишнего и распознавание характеристики.

Это готовый статический сайт. Установка зависимостей и сборка не нужны. Файлы index.html, style.css, app.mjs, engine.mjs, pedagogy.mjs, data.mjs и icon.svg должны находиться в одной папке. Все ресурсы загружаются с того же сайта. Внешних API, CDN, веб-шрифтов и авторизации нет.

Прогресс и личный рекорд сохраняются на устройстве ученика. Общего рейтинга и учётных записей нет.

## Публикация через GitHub Pages

1. Загрузить содержимое этой папки в корень публичного репозитория.
2. В Settings → Pages выбрать Deploy from a branch, main, /(root), Save.
3. Дождаться публикации и открыть адрес, показанный GitHub.
4. Проверить опубликованный адрес с российского домашнего и мобильного интернета без VPN.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Служебные файлы прежнего хостинга и его Git-история в комплект не входят. Файл .nojekyll отключает ненужную обработку статического сайта через Jekyll.
